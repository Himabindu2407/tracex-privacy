TraceX Privacy Policy

Last updated: November 12, 2026

TraceX is a browser extension designed to help users maintain their own browsing visit records independently of the browser's standard history interface.

1. Information We Collect

When enabled, TraceX may store website URLs, page titles, domain names and visit timestamps using the browser history permission. It does not intentionally collect passwords, keystrokes or form contents.

2. How Information Is Used

Browsing records are used to display visit history, search records, filter records and provide user-requested exports.

3. Data Storage

Browsing records are stored locally in the extension's browser storage. Records are subject to the configured two-calendar-month retention policy.

4. Sharing and Transmission

TraceX is designed for local storage. Any optional backup or external service must be separately disclosed and enabled before user data is transmitted. Do not use this statement until the extension's actual network behaviour has been verified.

5. User Controls

Users can pause or resume tracking and use available export and deletion controls. Tracking only works while the extension is installed, enabled and permitted to run.

6. Data Deletion

Users can delete records using the extension's available deletion controls. Uninstalling the extension or clearing extension storage may also remove locally stored records.

7. Permissions

TraceX requests browser history access to record website visits. This permission is used for the extension's browsing-history functionality.

8. Contact

For privacy questions or support, contact the TraceX project maintainer using the support contact published with the extension.
